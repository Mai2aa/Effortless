# E-formless AI Form Builder

![Overview](/overview.png)
## Overview

**AI Form Builder** is a modern web application designed to simplify the process of creating forms using artificial intelligence. Built on Next.js, it leverages ShadCN for component styling, Tailwind CSS for utility-first styling, and HyperUI for responsive and customizable UI components. This application empowers users to generate forms quickly and efficiently, enhancing productivity and data collection.

## Features

- **AI-Powered Form Generation**: Create forms effortlessly by providing simple descriptions. The AI suggests fields and layouts based on user input using the Gemini API.
- **Responsive Design**: Fully responsive forms that look great on any device, thanks to Tailwind CSS and HyperUI.
- **Customizable Components**: Use ShadCN components to easily customize the look and feel of your forms.
- **User-Friendly Interface**: Easy-to-navigate interface with drag-and-drop functionality for form creation.
- **Real-Time Preview**: See how your form will appear while you build it, ensuring that the final design meets your expectations.
- **Data Management**: Store and manage responses in a PostgreSQL database.
- **Authentication**: Secure user authentication with Clerk, enabling users to save their forms and access their dashboard effortlessly.

## Technologies Used

- **Frontend**: 
  - [Next.js] - Framework for server-rendered React applications.
  - [Tailwind CSS] - Utility-first CSS framework for rapid UI development.
  - [ShadCN] - Modern component library for building beautiful UIs.
  - [HyperUI] - A collection of pre-designed UI components for Tailwind CSS.

- **Backend**: 
  - [Node.js] - JavaScript runtime for building scalable network applications.
  - [Express] - Web framework for Node.js.
  - [PostgreSQL] - Relational database for storing form data and user information.

- **AI Integration**:
  - [Gemini API] - Utilized for AI-powered form generation and suggestions.

- **Authentication**: 
  - [Clerk] - User management and authentication service.

## Usage
1. **Sign Up / Sign In** : Create an account or log in using Clerk to access your dashboard.
2. **Create a New Form**: Use the AI-powered tool to describe your form and let the Gemini API generate fields for you.
3. **Customize Your Form**: Adjust field settings, styles, and layouts as necessary.
4. **Preview and Share**: View your form in real-time and share it with others for responses.

## Components Overview
1. Form Builder: The main interface for creating and managing forms.
2. Dashboard: A personalized space where users can view and manage their created forms.
3. Authentication: Secure access to the application with options for signing in and signing up.
